このアプリについて

  • たし算・ひき算・かけ算（九九）・わり算と、文章題を練習できます。
  • 広告なし・追加の課金なし・外部へのリンクなし。
  • 記録や名前は端末の中だけに保存し、外部に送りません（プライバシーポリシー）。
  • インターネットにつながっていなくても使えます。

よくある質問

保護者向けの画面（おうちのかたへ）はどこですか？

はじめの画面のいちばん下にある「おうちのかたへ」を押してください。学習レポート、名前の変更、記録のバックアップ、Face ID の設定があります。

はじめて開くときは、大人向けの確認問題に答えてから、保護者用の暗証番号（4けた）を決めます。確認問題は、表示された数字を指示どおりに並べ替えるなどして入力するものです。

暗証番号をわすれました
  1. 暗証番号の画面で「暗証番号をわすれた」を押します。
  2. 大人向けの確認問題に答えます。
  3. 新しい暗証番号を決めます。お子さまの記録はそのまま残ります。
Face ID・Touch ID で開けますか？

アプリ版では、「おうちのかたへ」の「Face IDで開く」でオンにできます（最初はオフです）。お子さまの顔や指紋もその端末に登録されているときは、お子さまが開けてしまうので、オフのままにしてください。

Face ID が通らないときは、アプリの暗証番号で開きます。端末のパスコードでは開きません。

機種変更のときに記録を引き継げますか？
  1. 今の端末で「おうちのかたへ」→「きろくを ほぞん」を押し、「"ファイル"に保存」から iCloud Drive などに保存します。
  2. 新しい端末にアプリを入れ、「おうちのかたへ」→「きろくを よみこむ」で、そのファイルを選びます。

暗証番号と Face ID の設定は端末ごとの設定なので、引き継がれません。新しい端末で決め直してください。

記録を消したいときは？

アプリを端末から削除すると、記録・名前・設定はすべて消えます。バックアップのファイルを作っていた場合は、そのファイルも削除してください。

音が鳴りません

iPhone・iPad が消音モード（マナーモード）になっていると、効果音や読み上げが聞こえないことがあります。消音を解除し、音量を上げてください。アプリの「⚙️ せってい」で「こうかおん」「よみあげ」がオンになっているかも確かめてください。

読み上げの声を変えたい・もっと自然な声にしたい

「⚙️ せってい」の「よみあげ の こえ」で選べます。iPhone・iPad では「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」から、高品質な声をダウンロードできます。
