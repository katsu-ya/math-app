# けいさん れんしゅう

小学生向けの算数の計算練習アプリです。
`index.html` の1ファイルだけで動きます（HTML / CSS / JavaScript）。
https://katsu-ya.github.io/math-app/ をホーム画面に追加すると、アプリのように全画面で使え、オフラインでも動きます（PWA）。

## つかいかた

1. `index.html` をブラウザ（Chrome・Safari・Edge など）で開きます。
   - はじめて開いたときは「はじめてガイド」が出て、そのあとに「なまえを おしえてね」の画面が出ます（どちらも飛ばせます）。
2. 「どの けいさん を する？」で、たしざん・ひきざん・かけざん・わりざん から1つ選びます。
3. 「むずかしさ は？」で、4つの難しさから1つ選びます。
4. 「スタート！」を押すと、10問が1問ずつ出ます。
5. 数字ボタンで答えを入れて「こたえあわせ」を押します。
   - 正解：「◯ せいかい！」と表示され、「ピンポン」と音が鳴って、1.5秒後に次の問題へ進みます。
   - 不正解：「✕ ざんねん…」と正しい答えが表示され、「ブブー」と音が鳴って、3秒後に次の問題へ進みます。
   - 音はブラウザで作っているので、音声ファイルは不要です。iPhone では消音モード（マナーモード）だと鳴りません。
6. 10問終わると、点数・かかった時間・全問のふりかえり（◯ / ✕）が表示されます。
   - ◯ は緑、✕ は赤の丸いしるしです。色が見分けにくくても、形で正解・不正解が分かります（計算の「×」とまちがえないよう、丸の中に入れています）。
   - 音を鳴らすか、問題文を読み上げるかは「⚙️ せってい」で切りかえられます。

パソコンでは、キーボードの数字キーで入力し、Enter キーで「こたえあわせ」もできます。

## かけざん の だん（九九の段を選ぶ）

「🔢 けいさん」で「かけざん」を押すと、「なんの だん？」の画面が出ます。

- 1〜9の段のボタンから、練習したい段を1つ選びます。別の段を押すと、前の選択は外れます。
- 「🌈 ぜんぶ」を選ぶと、1〜9の段すべてから出題します。
- 選んでいる段のボタンは、少し大きくなり、黒い枠と ✔ がついて、ほかのボタンはうすくなります。
- 出し方を選べます。
  - **じゅんばん**：3×1、3×2 … 3×9 のように順番に出します（ぜんぶのときは1の段から段ごとに）。
  - **ばらばら**：選んだ段の問題をまぜて出します。
- 選んだ段の ×1〜×9 をすべて出すので、問題数は1つの段なら9問、ぜんぶなら81問です。
- 結果画面では、段ごとに ×1〜×9 を並べ（正解は緑でぬりつぶし、不正解は白地に赤のわくとバツ線）、間違えた問題と正しい答えを表示します。全問正解した段には 🏅 がつきます。
- 前に間違えた苦手な問題に正解すると「にがて を こくふく！」と表示されます（段の問題はすべて出るので、苦手の問題を追加で混ぜることはしません）。
- 選んだ段と出し方はブラウザ（localStorage）に保存され、次に開いたときも同じ状態になります。
- 2けたのかけ算は、「もどる」で はじめの画面に戻り、「むずかしさ」を選んで「スタート！」を押します（今までどおりの出し方です）。
- 文章題モードでは「なんの だん？」の画面は出ず、今までどおり「むずかしさ」で出題します。
- 正解の経験値・全問正解のボーナス・カレンダーの問題数は、ふつうの練習と同じように数えます。

## ぶんしょうだい（文章題モード）

はじめの画面の「🔢 けいさん ／ 📖 ぶんしょうだい」で、文章題に切り替えられます。
「どの けいさん」「むずかしさ」は、ふつうの計算と同じ設定がそのまま使われます（数の範囲も同じです）。

| 計算 | 問題の種類 | 例 |
|---|---|---|
| たし算 | あわせて／ぜんぶで（もらう）／ふえると | おおきい りんごが 5こ、ちいさい りんごが 2こ あります。あわせて なんこ ですか。 |
| ひき算 | のこりは／ちがいは／なんこ おおい | えんぴつが 15本 あります。ともだちに 6本 あげました。のこりは なん本 ですか。 |
| かけ算 | 1さらに〜ずつ、〜さら分／1ふくろに〜ずつ／1人に〜ずつ くばる | 1さらに りんごが 3こずつ のって います。6さら分では、ぜんぶで なんこ ですか。 |
| わり算 | 〜人で同じ数ずつ分ける／1人に〜ずつ分けると何人／ふくろに同じ数ずつ入れる | クッキーが 32まい あります。4人で 同じ 数ずつ 分けると、1人分は なんまい ですか。 |

- りんご・みかん・いちご・あめ・クッキー・ふうせん・シール・えんぴつ・はな・ほん を使い、単位（こ・まい・本・さつ・人）をつけます。
  「本」「人」の読み方（1ぽん・2ほん・3ぼん、ひとり・ふたり など）は数に合わせてふりがなを変えます。
- 答えがマイナスになったり、割り切れなかったりする問題は出ません。かけ算・わり算では「1こずつ」「1人で分ける」は出しません。
- ひらがな中心で、漢字（人・分・同・数・入・兄・本）にはふりがながつきます。
- 問題文の下に、数がわかる絵文字の絵がつきます（例：🍎🍎🍎 ＋ 🍎🍎、かけ算は ひとまとまりごとに囲みます）。絵文字が30こを超えるときは絵を省略します。
- 🔊 ボタンで問題文を読み上げます（ブラウザの読み上げ機能を使います。もう一度押すと止まります）。読み上げに対応していないブラウザではボタンが出ません。
  - 画面の文章とは別に、読み上げ用のひらがなの文章を作って読みます。数と単位は正しい読み方にします（3こ → さんこ、1本 → いっぽん、8本 → はっぽん、4人 → よにん、3つ → みっつ など）。
  - 文（「。」）の区切りごとに少し間をあけ、子ども向けに少しゆっくり（速さ 0.85）・少し明るめの高さ（1.15）で読みます。
  - 日本語の声のうち、できるだけ自然な声（Natural・Google・高品質な声など）を自動で選びます。

## はじめてガイド

はじめて開いたときに、キャラクター（たまご）がふきだしで使い方を案内します（6ページ）。

- 内容：あいさつ → けいさん・むずかしさの選び方 → 答えの入れ方 → キャラクターの成長 → バッジとカレンダー → 困ったときはおうちの人に。最後のページには、保護者向けに「記録は端末の中だけに保存すること」と「おうちのかたへ」の場所を書いています。
- 「つぎ ▶」「◀ まえ」でページを移動します。パソコンでは ← → キーでも動きます。「とばす ▶▶」でいつでも終われます。
- 「🔊 よんで もらう」で、ふきだしの文を読み上げます（名前は入れていないので、どの声でも読み上げます）。
- 最後のページの「はじめる！」（または「とばす」）で、名前の登録に進みます。
- 一度見終わると、次からは出ません（`keisan-renshu-settings` の `guideSeen`）。この機能を入れる前から使っていて、名前の画面をもう見た人には出ません。
- あとから見直すときは、「おうちのかたへ」の「はじめてガイド」→「▶ はじめてガイドを見る」を押します。見終わると学習レポートに戻ります。

## なまえ

はじめて開いたときに、はじめてガイドのあとで名前とよびかたを登録できます。

- 名前（ひらがながおすすめ、10文字まで）を入れて、よびかたを「さん」「くん」「ちゃん」「よびすて」から選びます。
- 登録すると、名前を呼びかけるようになります。
  - はじめの画面の上：「ゆうさん、きょうも がんばろう！」
  - 正解したとき：「◯ ゆうさん、すごい！」（すごい・せいかい・やったね・さすが から毎回えらびます）。苦手な問題なら「◯ ゆうさん、にがて を こくふく！💪」
  - 結果画面：「💯 ゆうさん、ぜんもん せいかい！」など
  - レベルアップ：「ゆうさん、すごい！」、バッジ ゲット：「ゆうさん、おめでとう！」
  - 読み上げ：文章題の 🔊 で「ゆうさん、もんだい だよ。」と呼んでから問題を読みます。設定の「ためしに きく」でも名前を呼びます。
- 「あとで」を押すと、次からは聞きません。あとから「⚙️ せってい」の「なまえを かえる」で登録・変更できます（保護者用の暗証番号が必要です）。名前を空にして「けってい！」を押すと、名前を消せます。
- 名前はこの端末のブラウザ（localStorage）にだけ保存し、外部には送りません。
  - 読み上げの声のうち、インターネットを使う声（Chrome の「Google 日本語」、Edge の「Online (Natural)」など。設定の一覧で 🌐 がついている声）は、読む文章をインターネットに送ります。そのため、🌐 の声のときは名前を読み上げません（問題文は今までどおり読みます）。
  - 名前を読み上げてほしいときは、設定で 🌐 のついていない声（Mac・iPhone の Kyoko など、端末の中で読む声）を選んでください。

## せってい

はじめの画面のいちばん下の「⚙️ せってい」で、名前の変更、音と文字、読み上げの声の選択ができます。
パソコンでは、左に「なまえ」と「おと と もじ」、右に「よみあげ の こえ」の2列になります。

- 「なまえを かえる」で、名前とよびかたを変えられます。

**おと と もじ**（暗証番号なしで、子どもも切りかえられます）

- **🔔 こうかおん**：正解の「ピンポン」、不正解の「ブブー」、レベルアップやバッジのおいわいの音を、まとめてオン・オフします。オンにすると、ためしに「ピンポン」が鳴ります。
- **🔊 よみあげ**：オフにすると、文章題とはじめてガイドの 🔊 ボタンが出なくなり、「よみあげ の こえ」も表示しません。読み上げに対応していないブラウザでは、この行は出ません。
- **🔤 もじ の おおきさ**：「おおきい」にすると、文章題の問題文、答えあわせの説明、ふりかえり、キャラクター・カレンダー・バッジの説明、はじめてガイドのふきだしなど、読む文字を大きくします。ボタンや画面の並びは変えないので、パソコンでもスクロールせずに1画面に収まります。
- 選んでいるボタンはオレンジになり、✓ がつきます。
- どれも `keisan-renshu-settings` に保存され、バックアップにも入ります。

**よみあげ の こえ**

- 「おまかせ」では、その端末でいちばん自然な声を自動で選びます。★ は自然に聞こえやすい声、🌐 はインターネットを使う声です（🌐 の声では名前を読み上げません）。
- 「🔊 ためしに きく」で声を確かめられます。
- 選んだ声・名前・よびかたはブラウザ（localStorage）に保存されます。
- 使える声は端末やブラウザによって違います。iPhone・iPad では「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語」から高品質な声をダウンロードできます。
- アプリ版では、インターネットを使う声（🌐）は一覧に出さず、使いません。端末の中で読む声だけを使うので、問題文も名前も外部には送りません。
- iPhone・iPad では、声の一覧が少しおくれて届くことがあります。アプリを開いたときに読みこみを始め、「せってい」で一覧がまだからのときは、少し待ってから作り直します（10秒まで）。

答え方：

1. 3つの「しき」（例：3 ＋ 2、3 − 2、3 × 2）から1つ選びます。
2. 数字ボタンで答えを入れて「こたえあわせ」を押します（しきと答えの両方があっていて正解）。
3. 間違えたときは、正しい式（例：9 − 2 ＝ 7こ）と、短い考え方（例：「あげて へった『のこり』は ひきざん だよ」）が出ます。
   読み終わったら「つぎ の もんだい へ ▶」を押して進みます（Enter キーでも進めます）。

パソコンでは、左に問題文と答え、右にしきと数字ボタンの2列になり、スクロールせずに1画面に収まります。
文章題の記録も、カレンダー・経験値・バッジ・おうちのかたへのレポートに入ります。レポートの「よく間違える問題」では、しきを選び間違えたものを「文章題 式の選び方」としてまとめます。

## カレンダー（がんばりの きろく）

はじめの画面に、毎日どれだけ問題を解いたかが分かるカレンダーがあります。

- 「こたえあわせ」をするたびに、その日の問題数が1つ増えます。何回かに分けて解いても合計されます（途中で「やめる」を押しても、答えた分は数えます）。
- 1日に **10問以上** 解くと、その日付に赤い「○」がつきます。
- 1日に **20問以上** 解くと、その日付に「花丸」がつきます。
- 今日の日付は、オレンジのわくで目立つように表示されます。
- カレンダーの下に「きょう は 8もん。あと 2もん で ○」のように、今日の問題数と次のしるしまでの数が出ます。ほかの日付を押すと、その日の問題数が見られます。
- ◀ ▶ ボタンで前の月・次の月に切り替えられます。
- 読み上げソフト（iPhone の VoiceOver など）では、日付ごとに「10がつ 20にち、12もん、まる」「…、はなまる」「…、まだ」のように読み上げます。キーボードの Tab で日付を選び、Enter で問題数を表示できます。

記録はブラウザ（localStorage）に保存されるので、閉じても消えません。

- 記録はブラウザ・端末ごとに別々です（パソコンとスマホの記録は合算されません）。
- ブラウザの履歴やサイトデータを消すと、記録も消えます。
- アプリ版（App Store）では、記録を iPhone・iPad の設定の保存場所（UserDefaults）にも写しておくので、iOS が空き容量を作るために WebView のデータを消しても、記録は消えません（「アプリ版の記録の保存」を見てください）。
- 「今日」の日付は、使っている端末の日付で決まります。

## キャラクターの成長

はじめの画面に、いっしょに育つキャラクターと経験値のバーがあります（スマホでは画面のいちばん上、パソコンではカレンダーの上）。

- 1問正解するごとに **10** ポイント、1回の問題を全問正解すると **ボーナス 50** ポイントの経験値がもらえます（「なんの だん？」で選んだ問題も同じです）。
- 経験値がたまるとレベルアップして、見た目が変わります。

| レベル | すがた | 必要な経験値 |
|---|---|---|
| Lv.1 | たまご | 0 |
| Lv.2 | ゆれる たまご | 100 |
| Lv.3 | ひよこ | 400 |
| Lv.4 | げんきな ひよこ | 1000 |
| Lv.5 | にわとり | 2000 |

- レベルアップすると、10問の結果画面で「レベルアップ！」のお祝い（紙ふぶき・ファンファーレ）が出ます。
- キャラクターをさわると、ぴょんとはねます。
- 結果画面には、その回にもらった経験値が出ます。
- キャラクターの絵はこのアプリのオリジナルで、SVG で描いています（画像ファイルは不要）。

## バッジ

条件を達成するとバッジがもらえ、「バッジ ゲット！」と大きく表示されます（キラリーンと音が鳴ります）。
キャラクターの横の「🏅 バッジ」ボタンで一覧が見られます。まだのバッジはシルエットで表示され、「260 / 500」のようにあとどれくらいかも分かります。

| バッジ | 条件 |
|---|---|
| はじめの いっぽ | はじめて10問とく |
| 100もん / 500もん / 1000もん たっせい | 合計で100問・500問・1000問とく |
| 3にち / 7にち / 14にち れんぞく | 3日・7日・14日続けてとく |
| はじめての ぜんもん せいかい | 1回の問題をぜんぶ正解（10問、または「なんの だん？」で選んだ問題） |
| ぜんもん せいかい 10かい | 全問正解を10回 |
| はじめての はなまる | 1日に20問とく（カレンダーの花丸） |
| はなまる 10こ | カレンダーの花丸を10こ |
| 4つの けいさん | たし算・ひき算・かけ算・わり算すべてで正解する |
| くく マスター | 九九の81問（1×1〜9×9）をすべて1回以上正解する |
| スピードスター | 10問以上を1分以内に全問正解 |
| チャレンジャー | 「2けた むずかしい」で全問正解 |
| そだて めいじん | キャラクターを にわとり まで育てる |
| 1のだん 〜 9のだん マスター | 1回の練習の中で、その段の ×1〜×9 の9問をぜんぶ正解する（9こ） |

- 「だん マスター」のバッジは、バッジ一覧の下に1列で並びます。
- ここまでの25こ（ステージ1）をぜんぶ集めるまでは、バッジ一覧に「？？？ ひみつの バッジが あるかも…」とだけ出ます。

### ステージ2（ひみつの バッジ 20こ）

ステージ1を全部集めると、「あたらしい バッジ が あらわれた！」と金色の大きなお祝い（いつもより長いファンファーレと金色の紙ふぶき）が出て、ステージ2のバッジ20こが現れます。
ステージ2のバッジは、紺色のカードに金色のメダルで、ステージ1と見分けがつくようにしています。バッジ一覧は「ステージ1」「✨ ステージ2」のタブで切りかえます（現れたあとは、ステージ2を先に表示します）。

同じことをくり返すだけでなく、いろいろなモードを使いたくなる条件にしています。時刻（夜おそく など）を条件にしたバッジはありません。

| バッジ | 条件 |
|---|---|
| 2000もん たっせい | 合計で2000問とく |
| 50にち がんばった | 問題をといた日が合計50日（連続でなくてよい） |
| 30にち れんぞく | 30日続けてとく |
| はなまる 30こ | カレンダーの花丸を30こ |
| はなまる 1しゅうかん | 7日続けて花丸 |
| ぜんもん せいかい 30かい | 全問正解を30回 |
| 3れんぱつ | 3回続けて全問正解 |
| 4つの けいさん めいじん | たし算・ひき算・かけ算・わり算それぞれで全問正解（文章題をのぞく） |
| ぜんぶ の むずかしさ | ⭐〜⭐⭐⭐⭐の4つの難しさそれぞれで全問正解 |
| 2けた の たつじん | 「2けた むずかしい」で全問正解を5回 |
| くく 81もん いっき | 「なんの だん？」で全部の段を選び、81問を全問正解 |
| ばらばら くく | 「ばらばら」で全問正解した段が5つになる（「ぜんぶ」をばらばらで全問正解しても達成） |
| くく スピード | 段を1つ選び、9問を35秒以内に全問正解 |
| ひかり の はやさ | 10問以上を45秒以内に全問正解 |

| ぶんしょうだい 100もん | 文章題を100問正解 |
| ぶんしょうだい はかせ | 文章題のたし算・ひき算・かけ算・わり算それぞれで全問正解 |
| いろいろ チャレンジ | 1日のうちに、たし算・ひき算・かけ算・わり算・文章題をぜんぶやる |
| にがて こくふく 30かい | 「にがて」として出た問題を30回正解する |
| でんせつ の けいさん はかせ | ステージ2のほかの19こをぜんぶ集める |

- 時間は、こたえあわせのあと次の問題に進むまでの待ち時間もふくめた、1回の練習全体の時間です。
- 「ぶんしょうだい 100もん」は、この機能を入れる前の文章題の正解も（1問ごとの記録が残っている直近100日分は）数えます。「3れんぱつ」「ばらばら くく」「4つの けいさん めいじん」「ぜんぶ の むずかしさ」「2けた の たつじん」「ぶんしょうだい はかせ」「にがて こくふく 30かい」は、この機能を入れたあとから数えます。
- 「いろいろ チャレンジ」は、1問ごとの記録（直近100日分）から判定します。

- 問題数・連続日数・花丸のバッジは、カレンダーの記録から判定します。この機能を入れる前の記録で条件を満たしていれば、次に開いたときにまとめてもらえます。
- 経験値は、この機能を入れたあとに正解した問題から数えます。
- 記録（経験値・もらったバッジなど）はブラウザ（localStorage）に保存されます。

## 保護者用の暗証番号

保護者向けの場所は、4けたの暗証番号を入れないと開けません。

| 暗証番号が必要 | 暗証番号なしで使える |
|---|---|
| おうちのかたへ（学習レポート・記録の保存・バックアップの保存と読みこみ） | 問題を解く |
| なまえ・よびかたの変更（せってい の「なまえを かえる」） | キャラクター・バッジ・カレンダーを見る |
| | せってい の読み上げの声 |
| | はじめて開いたときの名前の登録 |

- **はじめて**「おうちのかたへ」などを開いたときに、暗証番号を決めます。
  - 子どもが勝手に決めて中に入れないように、先に「わすれたとき」と同じ大人向けの確認問題（下の「確認問題」）が出ます。正解すると、4けたの番号を決められます（確認のため2回入力）。
  - 確認問題をまちがえると、別の問題にかわります。途中で「もどる」を押したときは、まだ暗証番号は決まりません（次に開いたときも、確認問題から始まります）。
- 入力した数字は ●●●● のように隠れます。
- 同じ数字（0000・1111）、並び（1234・4321・0123）、くり返し（1212・1122）、2580 など、かんたんすぎる番号は使えません。
- 5回まちがえると、1分間は入力できません（開き直しても同じです）。確認問題のまちがいも、合わせて数えます。
- 保護者向けの画面を閉じて、子どもが使う画面に戻ると、自動でロックに戻ります。
- 暗証番号はこの端末のブラウザ（localStorage）にだけ保存し、外部には送りません。番号そのものではなく、ハッシュ（元に戻せない形）にして保存しています。
- 暗証番号は端末ごとの設定なので、バックアップのファイルには入りません。読みこんでも、今の暗証番号は変わりません。

### 確認問題（大人かどうかの確認）

5つの数字（1〜8、同じ数字なし）と、漢字の指示が出ます。指示どおりに数字を入力します。

| 指示 | 例：「3 5 2 1 7」のとき |
|---|---|
| 上の数字を降順に並べ替えて入力 | 75321 |
| 上の数字を昇順に並べ替えて入力 | 12357 |
| 上の数字を逆順に入力 | 71253 |
| 奇数番目の数字だけを入力 | 327 |
| 末尾の三桁を逆順に入力 | 712 |
| 各桁に一を加えて入力 | 46328 |

- 「降順」「昇順」「奇数番目」「末尾」「各桁」など、小学校では習わない言葉を使っています。指示は毎回変わり（同じ指示は続けて出ません）、答えは3けたか5けたなので、当てずっぽうでは通れません。計算の力ではなく、読む力で答える問題です（計算問題は、この算数アプリを使う子どもなら解けてしまうので使いません）。
- まちがえると、別の問題にかわります。暗証番号と合わせて5回まちがえると、1分間は入力できません。
- 指示の種類は `index.html` の `ASKS` で増やせます。

### 暗証番号をわすれたとき

1. 暗証番号の画面で「暗証番号をわすれた」を押します。
2. 確認問題に答えます。
3. 新しい暗証番号を決めます（2回入力）。子どもの記録と、Face ID の設定はそのまま残ります。

### Face ID・Touch ID で開く（アプリ版）

アプリ版（Capacitor）では、「おうちのかたへ」を暗証番号のかわりに Face ID・Touch ID（Android では指紋認証・顔認証）で開けるようにできます。

- 最初は**オフ**です。保護者が「おうちのかたへ」の「Face IDで開く」で「Face IDを使う」を押すと、その場で一度 Face ID の確認をして、通ったときだけオンになります。
- お子さまの顔や指紋もこの端末に登録されているときは、お子さまが開けてしまうので、オフのままにしてください。
- オンのときに Face ID が通らなかったり「暗証番号を使う」を押したりしたときは、いつもの暗証番号の画面になります。端末のパスコードでは開きません（お子さまが知っていることがあるため）。
- オン・オフはこの端末だけの設定です（暗証番号と同じ場所に保存し、バックアップには入りません）。
- Web 版（ブラウザ・ホーム画面に追加）では使えないので、この項目は表示されません。
- Face ID の画面には「Face IDをやり直す」と「暗証番号を使う」だけが出ます。iPhone の「パスワードを入力」（端末のパスコード）のボタンは出しません（`allowDeviceCredential: false` と `iosFallbackTitle: ""`）。Face ID が何度も通らずロックされたときも、端末のパスコードではなく、アプリの暗証番号の画面になります。
- 部品（プラグイン）は `@aparajita/capacitor-biometric-auth` です。iOS の `Info.plist` に `NSFaceIDUsageDescription` を書いてあります。`index.html` は部品の JavaScript を読みこまず、`Capacitor.Plugins.BiometricAuthNative` の `checkBiometry()` と `internalAuthenticate()`（ネイティブ側の名前）を直接使います。別の部品にするときは、`index.html` の `bioPlugin()`・`checkBio()`・`bioAuth()` を直します。

## おうちのかたへ（学習レポート）

はじめの画面のいちばん下にある「おうちのかたへ」を押すと、保護者向けの学習レポートが開きます。

- **取り組み**：今週・今月に解いた問題数、勉強した日数、連続日数、1問あたりの平均時間（先週との比較つき）
  - 週は月曜日はじまりです。
  - 連続日数は、今日まだ解いていなくても昨日まで続いていれば数えます。
- **計算ごとの正答率**：たし算・ひき算・かけ算・わり算それぞれの今週の正答率と、先週からの増減（▲▼はポイント差）
- **かけ算 段ごとの正答率**：1の段〜9の段それぞれの直近30日の正答率と問題数（1けたのかけ算・文章題で式があっていたものを含む）。正答率が70%未満の段は赤で表示し、「だん マスター」のバッジを取った段には 🏅 がつきます。
- **よく間違える問題**：直近30日の間違いを「7の段」「くり上がりあり」などに分けて、多い順に5つまで表示（よく間違える問題の例つき）
- **ひとことアドバイス**：結果に合わせて「よいところ」と「次のステップ」を1つずつ表示
- **はじめてガイド**：お子さまと一緒に、使い方の案内をもう一度見られます

記録について：

- 問題数・日数・連続日数は、カレンダーと同じ記録から計算します（この機能を入れる前の記録も含まれます）。
- 正答率・時間・よく間違える問題は、1問ごとの記録から計算します。この記録はこの機能を入れたあとに解いた問題からたまり、直近100日分をブラウザ（localStorage）に保存します。
- 1問に3分以上かかったものは、席を離れていたとみなして平均時間から除きます。

## にがて もんだい を おおめに だす

学習レポートの「よく間違える問題」と同じ調べ方で苦手を見つけて、練習のときに自動で多めに出します。

- 選んでいる計算・むずかしさで、直近30日に **2回以上**、かつ **2割以上** 間違えている種類（「かけ算 7の段」「たし算 くり上がりあり」など）を苦手とします。
- 苦手があるときは、10問のうち **3問（3割）** を苦手の問題にします。間違いが多い種類ほど選ばれやすくなります。
  - 半分は前に間違えた問題そのもの、半分は同じ種類の新しい問題です。
  - 苦手の問題は10問の中にばらばらに混ぜます。
- 苦手の問題に正解すると「◯ せいかい！ にがて を こくふく！💪」と表示されます。
- 正解が増えて間違いの割合が2割を下回ると、苦手ではなくなり、ふつうの出し方に戻ります。
- 文章題モードでも同じように混ぜます（「しきの選び方」の間違いは数では選べないので対象外です）。

## 画面

- 大きな文字・明るい色で、表示はひらがな中心です。
- スマホでは画面の数字ボタンで入力します（スマホのキーボードは出ません）。
- 数字ボタンは押した瞬間に反応します。ボタンのすき間を押しても、いちばん近いボタンが反応します。
- パソコンでは、ブラウザの高さに合わせて余白が変わり、スクロールしなくても1画面に収まります。
  はじめの画面は、左に「けいさん・むずかしさ」の選択、右にキャラクターとカレンダーの2列になります。
- スマホでは、カレンダーは「スタート！」ボタンの下にあります。
- スマホを横向きにしたとき（高さ 500px 以下）は、問題画面を左右2列にします（左に問題と答え、右に数字ボタン）。スクロールしなくても答えを入れられます。
- アプリ版では、iPhone は縦向きに固定し、iPad は縦・横どちらでも使えます（`ios/App/App/Info.plist` の `UISupportedInterfaceOrientations` と `UISupportedInterfaceOrientations~ipad`）。
- ノッチやダイナミックアイランドのある iPhone で、ホーム画面から開いたときやアプリ版でも、上の時計・電池の表示や下のホームバーとボタンが重ならないように、そのぶんのすき間をあけます（`viewport-fit=cover` と `env(safe-area-inset-*)`。横向きのときは左右にもすき間をあけます）。パソコンや、ノッチのない画面ではすき間は 0 です。
- 幅 320px の小さいスマホでも、問題画面の上の帯（何問目・時間・やめる）が1行に収まります。
- はじめの画面のタイトル「🧮 けいさん れんしゅう」は途中で改行しません。幅 440px 以下のスマホでは、画面の幅に合わせて文字を少し小さくして1行に収めます（幅 320px で約23px、375px で約27px）。
- 色はキャンディのようなパステル（ピンク・水色・黄緑・黄色・オレンジ・ラベンダー）です。背景はやさしいクリーム色（うすい黄色）で、水色・黄緑・オレンジ・ラベンダーの水玉と星の模様をうすく入れています。
- ボタンの文字は白ではなく濃い色（こい ピンク・紺・こい緑・こげ茶・こい紫）にしています。どのボタンも、文字と背景のコントラストは 6:1 以上です。白・クリーム色の上の文字（タイトルのオレンジ、正解の緑、土曜日の青、まだ来ていない日付のグレーなど）も 4.5:1 以上にしています（押せないときにうすくなるボタンは除く）。選んでいないボタンは白を重ねたうすい色にし、選んでいるボタンには黒い枠がつきます。色は `index.html` の `:root` で、ボタンの色（`--plus` など）、文字の色（`--on-plus` など）、下の影の色（`--sh-plus` など）を組にして変えられます。
- ボタンは丸く、下に同じ色の影をつけて、ぷっくり見えるようにしています。押すと少しへこみ、はなすと「ぽよん」とはずんで戻ります。
- 正解すると、「ゆうさん、すごい！」などの言葉が、明るいオレンジの大きめの太字（白いふちどりとゴールドの影つき）で「ぽよん」とはずんで出ます。同時に、答えのまわりに星やキラキラが0.7秒だけ飛びます（ボタンは押せるままです）。言葉の前には、明るいエメラルドグリーンの丸に白い ◯ のしるしがつきます。不正解は赤い丸に ✕ なので、色だけでなく形でも区別できます。
- はじめの画面のキャラクターは、ときどき首をかしげたり、はねたりします（問題を解いている間は動きません）。
- 端末の設定で「視差効果を減らす」「アニメーションを減らす」をオンにしていると、これらの動きは止まります。
- 読み上げソフト向けに、バッジ（もっているか、まだか）、九九の結果のマス（「3 × 4 ＝ 12、せいかい」など）、カレンダーのしるしの説明を読めるようにしています。正解のときの星やキラキラは読み上げません。
- 「やめる」や「おうちのかたへ」など、文字だけのボタンも、指で押しやすい高さ（44px 以上）にしています。
- 確認の画面（「とちゅう で やめる？」、記録の読みこみ）は、ブラウザの確認ダイアログではなく、アプリの中の画面で出します。「とちゅう で やめる？」が出ている間は、次の問題へ自動で進みません。
- 問題を解いている途中でほかのアプリに切りかえたり、画面を消したりした間は、「かかった じかん」に数えません。

| 正解したときのほめことば（名前があるとき） | `const PRAISES = [...]` |

| 不正解のあと次へ進むまでの時間 | `const AUTO_NEXT_NG_MS = 3000;` |
| 問題の数の範囲・条件 | `function makeProblem()` |
| 「なんの だん？」で選んだときの問題の出し方 | `function makeDanProblems()` |

| 「花丸」がつく問題数 | `const HANAMARU_COUNT = 20;` |
| 苦手の問題を出す割合・苦手とする条件 | `const WEAK_RATIO = 0.3;` `const WEAK_MIN_MISS = 2;` `const WEAK_MIN_RATE = 0.2;` |
| 文章題の文・考え方 | `const STORIES = {...}` |
| 文章題に出てくるもの・単位・絵文字 | `const ITEMS = [...]` |
| 文章題の絵を省略する数 | `const PIC_MAX = 30;` |

| 全問正解のボーナス | `const PERFECT_BONUS = 50;` |
| レベルアップに必要な経験値・すがたの名前 | `const STAGES = [...]` |

## 記録を消えにくくするしくみ

記録（キャラクター・バッジ・カレンダー・名前・設定など）は、この端末のブラウザ（localStorage）だけに保存しています。外部には送りません。

- **永続ストレージ**：開いたときに、ブラウザへ「この記録を自動で消さないで」と申請します（`navigator.storage.persist()`）。認められると、端末の空き容量が少なくなっても、ブラウザが記録を自動で消さなくなります。
  - Firefox では申請すると確認の画面が出るので、自動では申請しません。「おうちのかたへ」の「保護を申請する」ボタンから申請できます。
  - 認められるかどうかはブラウザが決めます（Chrome では、ホーム画面に追加したり、よく使ったりすると認められやすくなります）。
  - 「保護を申請する」を押した結果は、その場で表示します。認められたときは「✓ 保護されました」、断られたときは「ブラウザが今回は保護を許可しませんでした」と出し、次にできること（アプリとしてインストールすると許可されやすくなること、ときどき「💾 きろくを ほぞん」でバックアップすること）を案内します。ホーム画面のアプリで開いているときは、インストールの案内は出しません。
- **保存状態の表示**：「おうちのかたへ」の最後の「記録の保存」に、「✅ 保護されています」または「⚠️ まだ保護されていません」と表示します。
- **ホーム画面への追加の案内**：ブラウザで開いているときは、「ホーム画面に追加すると、きろくが きえにくくなります」と、その端末での追加方法を表示します。ホーム画面のアプリで開いているときは表示しません。
  - iPhone・iPad の Safari では、7日以上開かないと記録が消えることがあります。ホーム画面に追加したアプリには、この制限がありません。
- **バックアップ**：記録を1つのファイルに保存しておけます（次の「記録のバックアップ」）。

## 記録のバックアップ

「おうちのかたへ」の最後の「記録の保存」→「バックアップ」で使います。

- **💾 きろくを ほぞん**：名前・キャラクター・経験値・バッジ・カレンダー・学習レポートの記録・設定など、すべての記録を1つのファイルにします。
  - ファイル名は `keisan-名前-日付.json` です（例：ゆう → `keisan-yuu-2026-10-24.json`）。ひらがな・カタカナの名前はローマ字に、漢字の名前はそのまま入ります。名前がないときは `keisan-2026-10-24.json` です。
  - iPhone・iPad・Android では共有メニューが出ます。iPhone・iPad は「"ファイル"に保存」で iCloud Drive に保存できます。パソコンでは「ダウンロード」フォルダに入ります。
  - 保存の結果は、ボタンの下に表示します。
    - 共有メニューで保存先を選んだとき：「✓ 保存しました」と出て、「さいごに ほぞんした日」が新しくなります。
    - 共有メニューを閉じたとき：「保存をやめました」と出ます。日付は変わりません。
    - 保存できなかったとき：「⚠ 保存できませんでした」と、どうすればよいかを出します。日付は変わりません。
    - パソコンのダウンロードは、アプリからは成功したか分かりません。そのため「ファイルを保存できましたか？」と聞きます。「✓ 保存できた」を押したときだけ、日付が新しくなります。
  - ストア版（Capacitor）では、`@capacitor/filesystem` と `@capacitor/share` があればそれで保存します。どちらかがないときは、「保存できませんでした」と表示します。
  - どの場合も、今の記録は変わりません。
- **📂 きろくを よみこむ**：保存したファイルを選ぶと「いまの きろくは うわがきされます。よろしいですか？」と確認が出ます。「よみこむ」で、ファイルの記録に置きかわります（「やめる」なら今の記録のまま）。
  - けいさん れんしゅう で保存したファイル以外や、こわれたファイルは読みこみません（今の記録はそのままです）。
  - 新しいバージョンのアプリで保存したファイルを古いアプリで読もうとしたときは、「アプリを最新にしてから」と表示します。
  - ファイルの中身をすべて確かめてから書きこみます。書きこみの途中で失敗したときは、元の記録に戻します。
- **さいごに ほぞんした日**：最後に保存した日を表示します。保存してから1か月以上たつと（まだ保存したことがないときは、はじめて問題をといた日から1か月以上たつと）お知らせを出し、はじめの画面の「おうちのかたへ」に赤い点がつきます。
- ファイルの形にはバージョン番号（`v`）が入っています。将来アプリをアップデートしても、前に保存したファイルを読みこめます（`upgradeBackup()` で新しい形に読みかえます）。
- ファイルはこの端末（と、自分で選んだ iCloud Drive など）にだけ保存され、アプリが外部に送ることはありません。名前が入っているので、扱いに気をつけてください。

### iPhone・iPad で保存する

1. 「おうちのかたへ」を開き、いちばん下の「記録の保存」までスクロールします。
2. 「💾 きろくを ほぞん」をタップします。
3. 共有メニューが出たら、下のほうの「"ファイル"に保存」をタップします。
4. 「iCloud Drive」（または「このiPhone内」）を選び、フォルダを選んで、右上の「保存」をタップします。

### iPhone・iPad で読みこむ

1. 「おうちのかたへ」→「記録の保存」の「📂 きろくを よみこむ」をタップします。
2. メニューが出たら「ファイルを選択」をタップします。下の「ブラウズ」→「iCloud Drive」から保存したフォルダを開き、`keisan-…json` のファイルをタップします。
3. 「いまの きろくは うわがきされます。よろしいですか？」と出たら「よみこむ」をタップします。アプリが開き直して、記録が戻ります。

## アップデート

新しいバージョンを GitHub に push すると、次にアプリを開いたとき（またはアプリに戻ってきたとき）に、画面の上に「✨ あたらしい バージョン が あります」と出ます。タップすると新しいバージョンに切りかわります。記録はそのまま残ります。

- 問題を解いている途中は表示しません。
- アプリのファイルは端末に保存してあり（`sw.js`）、いつもはそれを使います。開いたときにサーバーのファイルと比べて、ちがっていれば新しいファイルを受け取っておき、タップしたときに入れかえます。バージョン番号を上げる作業はいりません。
- ファイルを増やしたときは、`sw.js` の `FILES` にも追加してください。
- `sw.js` は、アプリのページ（`./` と `index.html`）を開くときだけ、端末に保存したアプリを返します。`privacy.html`・`support.html` などほかのページは、いつもサーバーから受け取ります（アプリの一部ではないので `FILES` には入れません）。
- `index.html` をパソコンで直接開いたとき（`file://`）は、オフライン機能とアップデートのお知らせは動きません（ほかの機能は使えます）。

## ストア版（iOS アプリ）を作る

Capacitor で iPhone・iPad のアプリにしています（Bundle ID：`jp.katsuya.keisanrenshu`）。Web 版（GitHub Pages）は今までどおり `index.html` だけで動きます。

必要なもの：Node.js、Xcode（iOS シミュレーター）。部品は Swift Package Manager で入るので、CocoaPods はいりません。

```
npm install       # はじめて の とき だけ
npm run ios       # www/ を つくり、ios/ に うつして、Xcode を ひらく
```

- `npm run build` は、`index.html`・`manifest.webmanifest`・`sw.js`・`icons/` を `www/` に写します。アプリが使うファイルを増やしたときは、`package.json` の `build` にも足してください。
- `index.html` を直したら、もう一度 `npm run ios`（または `npm run build && npx cap sync ios`）をしてから Xcode で実行します。
- Xcode で、上のデバイスの選択からシミュレーター（例：iPhone 17）を選んで ▶ を押します。
- シミュレーターで Face ID を試すときは、メニューの「Features → Face ID → Enrolled」をオンにし、Face ID の画面が出たら「Matching Face」（通る）か「Non-matching Face」（通らない）を選びます。
- 入れている部品：`@aparajita/capacitor-biometric-auth`（Face ID・Touch ID）、`@capacitor/filesystem` と `@capacitor/share`（バックアップの保存）、`@capacitor/app`（Face ID の部品が使う）、`@capacitor/preferences`（記録の控え）。

### アプリ版の記録の保存

iOS の WebView の localStorage は、端末の空き容量が少ないときに OS が消すことがあります。そのためアプリ版では、記録を `@capacitor/preferences`（iOS は UserDefaults）にも写しています。

- アプリはこれまでどおり localStorage を読み書きします。`keisan-renshu-` で始まるキーを書いたり消したりすると、同じものを Preferences にも書いたり消したりします（`index.html` のいちばん最初の `<script>`）。
- アプリを開いたときに、localStorage の記録と Preferences をそろえます。この機能を入れる前から使っている人の記録も、最初に開いたときにそのまま Preferences に写ります。
- 開いたときに localStorage の記録が1つもなく、Preferences に記録があるときは、Preferences から戻してから開き直します（戻すかどうか決まるまで、画面は出しません）。
- バックアップの保存・読みこみ、記録のリセットは今までどおり使えます（読みこんだ記録も Preferences に写ります）。
- Web 版では何もしません。
- シミュレーターで確かめるときは、アプリを完全に終了してから、`Library/WebKit` を消して開き直します（iOS に消されたときと同じ状態になります。アプリの場所が見つからないときは何も消しません）：
  ```
  xcrun simctl terminate booted jp.katsuya.keisanrenshu
  C=$(xcrun simctl get_app_container booted jp.katsuya.keisanrenshu data) && rm -rf "$C/Library/WebKit"
  ```
- `www/` と `node_modules/` は作り直せるので、GitHub には上げません（`.gitignore`）。`ios/` は上げます。
- アイコンは、明るい黄色に、たまごから顔を出したひよこ（アプリのキャラクター）と＋×の絵です。起動画面は、アプリの背景と同じクリーム色に同じ絵です。絵を直すときは `icons/icon.svg`（起動画面は `icons/splash.svg`）を直して、`python3 tools/make-icons.py` を実行します。Web 版のアイコンと iOS のアイコン・起動画面がまとめて作り直されます。

### アプリ版で出さないもの

アプリ（`isNativeApp` が true）のときは、Web 版向けの次のものを出しません。Web 版はこれまでどおりです。

- 「おうちのかたへ」の記録の保存の欄の、「ホーム画面に追加すると…」の案内と、ブラウザの「保護されています／保護を申請する」。かわりに、バックアップをすすめる一文を出します。
- ブラウザへの保護の申請（`navigator.storage.persist()`）。
- オフライン用のしくみ（Service Worker）と「✨ あたらしい バージョン が あります」。アプリの新しい版は App Store から届きます。
- 「このブラウザだけに保存」などの言葉は、「この端末のアプリの中」などに変えます。

```
package.json            ストア版を作るための部品と、npm run build / npm run ios
capacitor.config.json   ストア版の設定（Bundle ID・アプリの名前・www/）
ios/                    ストア版の iOS（Xcode）プロジェクト
tools/make-icons.py     アイコン（Web 版・iOS）と起動画面の PNG を作る（Google Chrome と Pillow を使う）
APP_STORE.md            App Store に申請するときの文章・質問の答え・スクリーンショットの撮り方の下書き
STORE_CHECK.md          ストアに出す前の点検の記録
README.md               このファイル
```
