たまごと けいさん れんしゅう（小学生向けの計算練習アプリ）

このアプリについて

  • たし算・ひき算・かけ算（九九）・わり算、文章題、筆算（ひっさん）、時計の読み方を練習できます。
  • 30日間 無料でためせます（0円・お試しが終わっても自動で課金されません）。そのあとも続けるときは、月額300円（税込）の登録で、すべての機能を使えます。
  • 広告なし。お子さまが使う画面には、外部へのリンクや購入の案内はありません。
  • 記録や名前は端末の中だけに保存し、外部に送りません（プライバシーポリシー）。
  • インターネットにつながっていなくても使えます。

料金・お試し・解約（アプリ版）

料金はいくらですか？

はじめの30日間は無料でお試しできます（0円）。そのあとも続けて練習するときは、月額300円（税込）の自動更新サブスクリプションに登録してください。無料版・有料版の区別はなく、お試し中も登録中も、すべての機能を同じように使えます。年額のプランはありません。

お試しの前でも、アプリを入れてから最初の1回（10問）だけ、練習を体験できます。

30日間のお試しは、どうやって始めますか？
  1. 「おうちのかたへ」を開きます（保護者用の暗証番号で開きます）。
  2. いちばん上の「ご利用のプラン」で「30日間 無料で ためす（0円）」を押します。
  3. Apple の購入の確認（0円）が出るので、確認します。

ボタンを押した日を1日目として、30日目まで使えます（例：10月28日に始めたら11月26日まで）。「ご利用のプラン」に「お試しは あと○日（○月○日まで）」と出ます。

お試しが終わったら、自動でお金がかかりますか？

かかりません。お試しは0円の購入で、終わっても自動で月額の登録には切り替わりません。終わる3日前から、「ご利用のプラン」にお知らせと「この30日間のふりかえり」が出ます。

お試しが終わったあとは、練習はできなくなりますが、記録（キャラクター・バッジ・カレンダー・学習レポート）はなくならず、見ることとバックアップはこれからもできます。あとから登録すれば、続きから練習できます。

月額の登録のしかた

「おうちのかたへ」→「ご利用のプラン」の「月額300円（税込）で登録する」を押し、Apple の購入の確認で登録します。お試し中でも登録できます（登録すると、その日から月額が始まり、お試しの残りの日数はなくなります）。お支払いは Apple ID で行われ、1か月ごとに自動で更新されます。更新日の24時間前までに解約しないと、次の月も更新されます。

解約のしかた

iPhone・iPad の「設定」→ 自分の名前 →「サブスクリプション」で、このアプリを選んで「サブスクリプションをキャンセルする」を押します。アプリの「おうちのかたへ」→「ご利用のプラン」の「登録の確認・解約」からも、同じ画面を開けます。

解約しても、その月の終わり（次の更新日の前）までは使えます。アプリを削除しても、サブスクリプションは解約されません。

入れ直したら・機種を変えたら、お試しや登録はどうなりますか？

お試しと登録は Apple ID に記録されています。同じ Apple ID なら、入れ直したり新しい端末に入れたりしても、そのまま引き継がれます（お試しを最初からやり直すことはできません）。表示が戻らないときは、「ご利用のプラン」の「購入を復元」を押してください。

記録（名前・キャラクター・カレンダー・学習レポートなど）は端末の中だけにあるので、アプリを削除すると消えます。前に「💾 きろくを ほぞん」で作ったファイルがあれば、入れ直したあとで「おうちのかたへ」→「📂 きろくを よみこむ」で読みこむと、続きから使えます（下の「機種変更のときに記録を引き継げますか？」と同じ手順）。

お子さまの記録は端末の中にあるので、機種変更のときはバックアップで引き継いでください（下の「機種変更のときに記録を引き継げますか？」）。

家族の端末でも使えますか？（ファミリー共有）

ファミリー共有に対応しています。購入した人の家族グループの家族（きょうだいの端末や、保護者の端末など）も、追加の料金なしで使えます。家族の端末で使えないときは、その端末の「おうちのかたへ」→「購入を復元」を押してください。

子どもが勝手に購入しませんか？

購入・登録のボタンは、保護者用の暗証番号（または保護者がオンにした Face ID・Touch ID）で開く「おうちのかたへ」の中だけにあります。お子さまが使う画面には、購入の案内は出しません（練習できないときは「おうちのかたに きいてね」とだけ出ます）。

お子さま用の Apple ID で「承認と購入のリクエスト」をオンにしている場合は、保護者の方の承認を待つ状態になります。承認されると使えるようになります。

よくある質問

保護者向けの画面（おうちのかたへ）はどこですか？

はじめの画面のいちばん下にある「おうちのかたへ」を押してください。ご利用のプラン（お試し・登録）、学習レポート、名前の変更、記録のバックアップ、Face ID の設定があります。

はじめて開くときは、大人向けの確認問題に答えてから、保護者用の暗証番号（4けた）を決めます。確認問題は、表示された数字を指示どおりに並べ替えるなどして入力するものです。

暗証番号をわすれました
  1. 暗証番号の画面で「暗証番号をわすれた」を押します。
  2. 大人向けの確認問題に答えます。
  3. 新しい暗証番号を決めます。お子さまの記録はそのまま残ります。
Face ID・Touch ID で開けますか？

アプリ版では、「おうちのかたへ」の「Face IDで開く」でオンにできます（最初はオフです）。お子さまの顔や指紋もその端末に登録されているときは、お子さまが開けてしまうので、オフのままにしてください。

Face ID が通らないときは、アプリの暗証番号で開きます。端末のパスコードでは開きません。

機種変更のときに記録を引き継げますか？
  1. 今の端末で「おうちのかたへ」→「きろくを ほぞん」を押し、「"ファイル"に保存」から iCloud Drive などに保存します。
  2. 新しい端末にアプリを入れ、「おうちのかたへ」→「きろくを よみこむ」で、そのファイルを選びます。

暗証番号と Face ID の設定は端末ごとの設定なので、引き継がれません。新しい端末で決め直してください。

記録を消したいときは？

アプリを端末から削除すると、記録・名前・設定はすべて消えます。バックアップのファイルを作っていた場合は、そのファイルも削除してください。

音が鳴りません

iPhone・iPad が消音モード（マナーモード）になっていると、効果音や読み上げが聞こえないことがあります。消音を解除し、音量を上げてください。アプリの「⚙️ せってい」で「こうかおん」「よみあげ」がオンになっているかも確かめてください。

読み上げの声を変えたい・もっと自然な声にしたい

「⚙️ せってい」の「よみあげ の こえ」で選べます。iPhone・iPad では「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」から、高品質な声をダウンロードできます。
